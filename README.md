## 本地开票工作台

给个人工作室和做小生意的人用。我在香港处理业务时，需要给对方提供合同、形式发票、收据。这些文件编码会让我头疼，这些模版的格式我也想统一。最最最想一眼看清的是：这笔钱收到了吗？给客户的单据开了吗？ 所以我需要一个我自己的工作台去记录这些。
工作台把客户、金额、收款状态和单据放在同一笔业务里，还包括香港常见的两种结算货币：港币和美元分开记。

## 爱你老己 · 像素小院

我想**看见自己，把自己的一天具象化**。工作经常让人觉得时间流逝飞快，早上进公司还是白昼，但是下班走出写字楼天空已经擦黑，脑袋昏沉却也觉得属于自己的一天就这么飞速流逝了，好像一回到家一闭眼一睁眼就又刷新到了工位一样。
我想把每天一些细小的事情可视化，这样一天下来看看虚拟小人也许会有直观的感觉：
开会，小人就去村口开会；我午休，他也躺进吊床。忙到下午，看一眼小院，也会想起自己今天喝过几次水。现在可以手动记录，也可以在心愿墙上留一句“今天不许加班了！！！！！”。
