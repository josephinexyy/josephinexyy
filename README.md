## 本地开票工作台

给个人工作室和做小生意的人用。我在香港处理业务时，最想一眼看清的是：这笔钱收到了吗？给客户的单据开了吗？工作台把客户、金额、收款状态和单据放在同一笔业务里，港币和美元分开记。

## 爱你老己 · 像素小院
