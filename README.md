## 正在做的项目

**本地开票工作台**

给个人工作室、自由职业者和个体经营者做的开单工具，尤其关注香港小生意。把客户、业务、发票和收款记录放在一起，让一个人做生意时也能把记录整理清楚，跟客户对接得更有条理、更体面。

支持港币／美元、三语界面、PDF 导出、本地客户资料识别与完整备份。可以用自己的资料正式开单，也可以先体验虚构演示。

[在线使用](https://josie-billing-workspace.coral-ox-0471.chatgpt.site) · [体验演示](https://josie-billing-workspace.coral-ox-0471.chatgpt.site/?demo=1) · [下载离线包](https://josie-billing-workspace.coral-ox-0471.chatgpt.site/Billing-Workspace-v0.2.0.zip) · [产品案例](https://github.com/josephinexyy/product-portfolio/blob/main/cases/local-billing-workspace.md)

**爱你老己 · 像素小院**

一个把自己真实的一天映射成像素生活的小游戏：午休是躺吊床，开会是去村口，喝水「大水理论」和上厕所也对应自己的行为。无聊时可以闲逛、种小苗，慢慢照顾自己。

希望逐渐补上记录与提醒、会议期间的心率变化，以及工资到账后麦子成熟、自己收获的体验。当前为手动操作与模拟事件原型，尚未接入 Apple Watch、飞书或真实薪资数据。

[在线玩](https://aini-laoji-garden-v7.coral-ox-0471.chatgpt.site) · [下载离线包](https://aini-laoji-garden-v7.coral-ox-0471.chatgpt.site/downloads/aini-laoji-v0.8.0.zip) · [玩法与设计](https://github.com/josephinexyy/product-portfolio/blob/main/cases/aini-laoji.md)

## 我喜欢琢磨的小事

- 让操作更顺手、让人觉得被照顾到的小设计。
- 能省去重复劳动的小硬件、小软件。
- 用户在意哪些细节，愿意为怎样的体验付费。
