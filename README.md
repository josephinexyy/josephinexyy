## 正在做的项目

**[Local Billing Workspace｜本地开票工作台](https://github.com/josephinexyy/local-billing-workspace)**

**[下载即用 · v0.2.0](https://github.com/josephinexyy/local-billing-workspace/releases/download/v0.2.0/Billing-Workspace-v0.2.0.html)** · [完整离线包 ZIP](https://github.com/josephinexyy/local-billing-workspace/releases/download/v0.2.0/Local-Billing-Workspace-v0.2.0.zip)

下载 HTML → 在 Chrome 中打开 → 点击右上角“体验演示”。不用注册账号或安装开发工具。

给个人工作室、自由职业者和个体经营者做的本地开单工具，尤其关注香港小生意的使用场景。把客户资料、业务往来、发票和收款记录放在一起，让一个人做生意时也能把记录整理清楚，跟客户对接得更有条理、更体面。

支持港币 / 美元、三语界面、PDF 导出、本地客户资料识别与备份恢复。从自己的实际需要出发，负责需求、使用体验和迭代，借助 AI 把想法做出来。

**[爱你老己｜像素小院](https://github.com/josephinexyy/aini-laoji)**

一个把自己真实的一天映射成像素生活的小游戏：午休是躺吊床，开会是去村口，喝水「大水理论」和上厕所也对应自己的行为。希望逐渐补上记录与提醒、会议期间的心率变化，以及工资到账后麦子成熟、自己收获的体验。当前公开版为手动操作与模拟事件原型，尚未接入 Apple Watch、飞书或真实薪资数据。

**[下载即玩 · v0.8.0](https://github.com/josephinexyy/aini-laoji/releases/download/v0.8.0/aini-laoji-v8.html)** · [玩法与介绍](https://github.com/josephinexyy/aini-laoji#readme) · [提建议](https://github.com/josephinexyy/aini-laoji/issues/new/choose)

下载 HTML 后用 Chrome 打开即可。还在边玩边改，欢迎试玩、提建议和帮忙捉虫。

## 我喜欢琢磨的小事

- 让操作更顺手、让人觉得被照顾到的小设计。
- 能省去重复劳动的小硬件、小软件。
- 用户在意哪些细节，愿意为怎样的体验付费。

欢迎交流好用的小工具、值得欣赏的产品细节，以及使用后的真实感受。
